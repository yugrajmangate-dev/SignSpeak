# Pretrained model attribution

The unmodified `gesture_recognizer.task` bundle is from Google MediaPipe, version 1, float16.

- [Official documentation](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer)
- [Official download](https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task)
- [Model card](https://storage.googleapis.com/mediapipe-assets/gesture_recognizer/model_card_hand_gesture_classification_with_faireness_2022.pdf)
- [MediaPipe repository and license](https://github.com/google-ai-edge/mediapipe)

The upstream MediaPipe Apache license is included as `MEDIAPIPE_LICENSE.txt`. No model authorship or custom training is claimed by team YUGA.

SHA-256: `97952348cf6a6a4915c2ea1496b4b37ebabc50cbbf80571435643c455f2b0482`

The upstream model card explicitly excludes full sign-language translation. This project presents a limited gesture-label-to-speech demonstration, not a validated sign-language translator.
